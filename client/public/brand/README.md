# EthioFreelance brand assets

These files preserve the selected logo artwork, including the original suitcase, freelancer, laptop, and check mark. The SVG files embed the selected image so the artwork stays consistent across exports.

| Use | Files |
| --- | --- |
| Logo on light backgrounds | `logo-horizontal.svg`, `logo-horizontal.png` |
| Logo on dark backgrounds | `logo-horizontal-light.svg`, `logo-horizontal-light.png` |
| Centered logo | `logo-stacked.svg`, `logo-stacked.png` |
| Symbol without wordmark | `mark.svg`, `mark-512.png`, `mark-1024.png` |
| Square app and profile icon | `app-icon.svg`, `app-icon-192.png`, `app-icon-512.png`, `app-icon-1024.png` |
| Browser and touch icons | `favicon.svg`, `favicon.ico`, `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, `apple-touch-icon-180.png` |
| Wide banner | `banner-wide.svg`, `banner-wide.png` |
| Social preview banner | `banner-social.svg`, `banner-social.png` |
| Promotional badges | `badge-brand`, `badge-find-work`, `badge-find-talent` in SVG and PNG |

Use the logo on a white or light surface. Keep its proportions when resizing.
